## How I work through each problem

1. Solve it cold (no hints) for at least 20-30 minutes.
2. If stuck, check hints before checking the solution.
3. Write the solution in `solution.py`.
4. Fill out `notes.md` with approach, complexity, and what I'd do differently.
5. Update the table above and commit.
